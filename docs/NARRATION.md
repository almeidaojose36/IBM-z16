# Narration script (96 s)

Timed to the shots in `src/story.js`. About 210 words, which fits 96 seconds at a calm pace.
Every figure is from the IBM z16 (3931) Technical Guide; see `RESEARCH.md`.

| Time | Shot | Narration |
|---|---|---|
| 0:00 | Closed frame, slow orbit | This is an IBM z16. It costs more than a million dollars, and almost nobody gets to open one. So let's open one. |
| 0:06 | Doors and side covers come off | Under the covers it is a standard 19-inch rack, 42 units tall. A big system bolts four of them together. |
| 0:12 | Interior, top to bottom | At the top, two support elements and two network switches run the machine. Below them, an I/O drawer. Then the processor drawers. And at the bottom, a radiator. |
| 0:24 | Camera moves to the rear | Every cable connects at the back. Sixteen adapter cards per I/O drawer, including this one: a tamper-responding crypto module built for quantum-safe encryption. |
| 0:35 | CPC drawer slides out | This is where the work happens: the central processor complex drawer. Five rack units tall, and a system can have four. |
| 0:42 | Cover off, labels | Inside: five fans, forty-eight memory slots, twelve fanout cards, and four processor modules hidden under water-cooled cold plates. |
| 0:47 | Drawer explodes | Almost everything here is redundant and can be replaced while the machine keeps running. One drawer holds up to ten terabytes of memory. |
| 0:58 | Cold plates lift, DCM rises | Lift the cold plates and you find the dual chip module. Water takes its heat to the radiator, in a sealed loop. |
| 1:05 | Lid off | Take off the thermal cap, and there are two processors on one module, with 4,753 pins underneath. |
| 1:14 | Telum floor plan | Each one is an IBM Telum chip. Seven nanometres, twenty-two and a half billion transistors, eight cores at 5.2 gigahertz, and an AI accelerator built into the silicon. |
| 1:22 | Reassembly | Put it all back, and a fully built z16 has two hundred of those cores and forty terabytes of memory. |
| 1:31 | Closed frame | A million-dollar computer, designed never to be switched off. |
